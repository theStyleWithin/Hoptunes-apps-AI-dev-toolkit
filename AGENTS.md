# For coding agents

**Where you may write code:** only in the person's **own** repositories (a new repository of theirs for the app, and/or their own fork of Hop-tunes). **Never in the
official Hop-tunes repository** (you very likely cannot reach it, and must not try), and **never in this toolkit or the person's fork of it**: they only keep it
handy to forward to you. Read `AGENT-BRIEF.md` first: it has the rules.

If the person only gave you a link and no request: read this toolkit, ask them for the link to **their fork of Hop-tunes** (they should fork both Hop-tunes and this
toolkit on GitHub; the fork is the copy you read, build and test with), then ask them warmly whether they want to make an app for Hop-tunes (details in the README
and the brief). The brief tells you what Hop-tunes apps are, the rules you must follow (offline first, no telemetry, tests), and how to work with the person you are
helping. Then follow the links in it.

You do not need the Hop-tunes author's permission to make an app, and you must not credit the author with the work: see `PERMISSION-AND-CREDIT.md`.
