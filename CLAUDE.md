# For coding agents

If the person only gave you a link and no request: clone this toolkit and the Hop-tunes repository (https://github.com/theStyleWithin/Hop-tunes) to read
them, then ask them warmly whether they want to make an app for Hop-tunes (details in the README and the brief). Read `AGENT-BRIEF.md` first. It tells you what Hop-tunes apps are, the rules you must follow (offline first, no telemetry, tests), and how to
work with the person you are helping. Then follow the links in it.

You do not need the Hop-tunes author's permission to make an app, and you must not credit the author with the work: see `PERMISSION-AND-CREDIT.md`.
